# Security Policy

## Supported Versions

Only the latest release of Piwaku receives security fixes. Releases are
published through the Piwaku GitHub repository; the app has no in-app updater.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/anamaxlec/Piwaku/security/advisories/new

If that doesn't work for you, email hi@egoist.dev.

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Piwaku version (Piwaku → About Piwaku) you tested.
